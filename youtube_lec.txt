################################# Git Stashing #########################################

What is a stash?
A stash is like a temporary shelf where Git stores your uncommitted changes so you can work on something else.

1. git stash        ---chagnes will be stashed in one place.
2. git stash list   ---this will show all the stashed chages in the list format.
3. git stash pop    ---this will bring all the temp chages to back to their place.
4. git stash apply  ---this will apply the chages directly to the branch without poping them.

>>>>>>>>>>>>>>>>>>>>>>> When to use which? >>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>

Use git stash apply if you want to keep a backup of the stashed changes in case you need to apply them again.
Use git stash pop when you're confident you no longer need the stash after restoring the changes.


####################################### Git Tags ############################################

Git tags are used to mark a specific commit with a permanent, human-readable name. They are most commonly used to identify releases, versions, or other important milestones.

1. Annoted Tags  	---Annotated tags store additional information like the author, date, and a message.
2. Lightweight Tags 	---This will have the light info about the commit.

>>>>>>>>>>>>>>>>>>> Git Tag commands >>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>>

1. git tag -a <tag_string> -m "message"     ---This will create the annoted Tag.
2. git show <tag_string>   		    ---To view the Tag details.
3. git tag     		    		    ---This will shows all the tags list.
4. git tag <tag_string>     	            ---This will create the lightweight tag.
5. git tag -d v1.0			    ---This will delete the tag locally.
6. git push origin --delete v1.0            ---This will delete the tag remotely.
